# RecordCurator 

![](/assets/images/RecordCurator_Icon.png)


RecordCurator is a software developed during my PhD which allows a user to integrate biodiversity data (in particular digitised specimen data) from different sources and produce 'curated' datasets. Different sources include GBIF, Herbarium-internal databases and taxonomists' personal, expert determined datasets.
In particular, RecordCurator attempts to best-possibly standardise records to identify and reconciling duplicate specimens. This is crucial, as in particular in tropical regions duplicate specimens represent a significant proportion of records (at least for trees and other large growth form plants). Not reconciling duplicates risks biasing results, although to my knowledge this is something we are yet to fully quantify. 

RecordCurator makes use and builds on a number of incredible resources, without much of plant biodiversity informatics would be very hard to do. This includes online accessible databases such as the Harvard Index of Botanists ([HUH](https://kiki.huh.harvard.edu/databases/botanist_index.html)), [World Flora Online](https://wfoplantlist.org/), [POWO](https://powo.science.kew.org/), but also tools and workflows such as [CoordinateCleaner](https://github.com/ropensci/CoordinateCleaner).

# Documentation

This is a start for the documentation of the RecordCurator software found [here](https://github.com/SJRStreiff/RecordCurator). Until this is finalised, refer to the Github repo for instructions on using *RecordCurator*

## Current status of the docs and software


Note that I am planning to update several steps of the processing to make the software much more powerful and more widely applicable, allowing for better integration across databases following and furthering FAIR data use. 

The documentation is in the process of being transferred here, and examples being produced to make life easier using the software. In the meantime, if you need help, notice any bugs, or would like to chat, feel free to [contact me](mail).
